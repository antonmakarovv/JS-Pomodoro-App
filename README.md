# Pomodoro App

A simple and elegant Pomodoro timer application built with vanilla HTML, CSS, and JavaScript.

## Features

- **Work Timer** - 45-minute focus sessions
- **Break Timer** - 10-minute break intervals
- **Pause/Resume** - Pause and resume the timer at any time
- **Reset** - Clear the timer and start fresh
- **Visual Feedback** - Color changes and animations when timer completes
- **Responsive Design** - Works on desktop and mobile devices
- **Status** - Check your work status
- **Work Sessions** - Check your work sessions

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)

### Running the App

1. Clone the repository:
   ```bash
   git clone https://github.com/antonmakarovv/JS-Pomodoro-App.git
   ```

2. Open `index.html` in your browser:
   ```bash
   open index.html
   ```
   
   Or simply double-click the `index.html` file.

## Usage

1. Click **Work** to start a 45-minute work session
2. Click **Break** to start a 10-minute break
3. Click **Pause** to pause/resume the timer
4. Click **Reset** to stop and clear the timer

The display turns green during break time. When a session ends, the timer automatically switches between work and break modes.
